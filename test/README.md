To Run program:

First, create a virtual python environment, and install paddleocr

On Mac/Linux:

`python3 -m venv venv`

`source venv/bin/activate`

`python -m pip install paddleocr`

Then, you should be able to run it:

`python3 test_paddleocr.py [-h] [--image IMG [IMG ...]]`

If you do not specify an input image, a default one provided by paddleorc is used.
